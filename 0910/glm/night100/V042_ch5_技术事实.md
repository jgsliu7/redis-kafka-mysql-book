- 第 5 条：逐行读了 Redis 7.4 `src/commands.c` 全文（8 行，仅 include `commands.def`）与 `src/` 目录树。
- 已核实为正确、未列入意见的版本断言：Kafka Tiered Storage 3.6 EA / 3.9 GA（L186）、redo log 8.0.30 改 `#innadb_redo` 前的 `ib_logfile*`（L126）、7.0 listpack 取代 ziplist 且旧编码加载时转换（L68）、Query Cache 8.0 移除（L113）、PG 12 table AM（L128）。
