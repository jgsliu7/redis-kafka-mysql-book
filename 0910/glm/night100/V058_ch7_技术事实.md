## 已核实、确认无误不列问题的点

- L172 "对应 KIP-679"：正确，KIP-679 即 3.0 把 acks 默认改为 all（同时 enable.idempotence 默认 true）。
- L67 "Redis 官方文档称之为 Raft-like"：归属成立，官方 Sentinel 文档/sentinel-spec 确以 Raft 相似描述该选举（多数派授权 + epoch，仅限选举、无日志复制）。
- L40 16384 槽 / 2KB bitmap、L92 `cluster-node-timeout` 默认 15s、L115 MTS 8.0.27 起默认 4、L42 MGR 硬上限 9、L184 KRaft 版本线（3.3 GA / 3.5 弃 ZK / KIP-866 3.4 EA→3.5 preview→3.6 GA / 3.9 bridge / 4.0 移除）、L156 KIP-480 粘性分区 2.4、L119 半同步"等 I/O 线程写 relay log 落盘即确认、不等 SQL 线程回放"的语义——均与官方文档一致。
