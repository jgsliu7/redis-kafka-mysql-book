# W32 · 只看图的老宋 · 读者报告

实验方式：只读全书 57 张 SVG（chapters/*/diagrams/fig-*.svg 逐张读源码）+ 各 chapter.md 里的"图 N-M"图注行，不读正文（图注所在行除外，个别条目引了紧贴图的那一句引出句）。检验目标：图 + 图注脱离正文能不能自足。

先说总体：57 张图里绝大多数配上图注能看懂七八成，数据自洽的居多（fig-2-2 跳表路径、fig-7-2 槽位加总 16384、fig-9-4 的 520−330=190、fig-9-7 的 min(5,2)=2 都对得上）。问题集中在两类：一是同一机制两张图口径不一（本章 6 条里有 4 条是这种），二是图注承诺了图里不存在的东西。以下 10 条按严重程度排序。

## 收尾总评（仍然只谈图）

57 张图的整体水准是"图注格式统一（图 N-M 标题。说明）、配色语义稳定（Redis 靛 / MySQL 琥珀 / Kafka 绿）、关键数字大多自洽"，自足性及格线以上的占绝大多数。最值得修的是跨图口径：同一个机制（MySQL 写链路、Kafka 请求/响应队列、Redis Set 的编码家族、Handler 线程池的定性）分别在两张图里被画成两样，单图各自成立、对图必打架——这类问题不读正文的读者最先撞上，恰恰是插图自足性最伤的地方。
