## 总体印象（供参考）

书写得比市面上"怎么用"的资料诚实，敢于写行为边界和取舍（如 9.2 对 min-replicas-max-lag 两套度量的澄清、7.2.3 对 AP/CP 之争的处理），PHP 时代的若干"常识"被它纠正了。但对"第一次要在生产搭 Redis Cluster"的读者，从"单实例不够"到"Cluster 能用"之间的台阶（拆实例、客户端集群模式、SELECT 禁用、hash tag 实战）几乎是空白——第 7 章把 Cluster 当机制讲透了，没当迁移路径讲，#3 和 #6 是这类读者最容易被带偏的两处。
