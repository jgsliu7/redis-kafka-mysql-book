# 读者067 · 五个九
身份：电信系统架构师，17年，爱好：篆刻
主读：第 7 章

## 五个问题

1. 【导读|逻辑论证】开头事故里「刚扣减的库存在网络恢复后被新主的数据覆盖了。用户下了单，仓库说没货」这两句我接不上因果：扣减写被丢的直接后果是库存计数「回吐」、显得更充裕，要等后续订单把这份多出来的库存吃掉，才会出现「下了单却没货」的超卖终局。中间这一环被压缩掉了，我分不清没货的到底是扣减被丢的那位用户还是后来占走回吐库存的用户——丢写事故复盘时因果链一环都少不得，建议把链条写全。

2. 【7.1|技术事实】CAP 段说这种一致性要求「保留真实时间先后」，表述偏强：线性一致性只要求不重叠的操作保留真实时间先后，并发（重叠）操作的先后是可以任意的。少了「不重叠」这个限定，做并发写的读者会以为真实时间上先发起的写一定先生效，这比线性一致性本身承诺的更多。

3. 【7.3.2|技术事实】「从节点 I/O 线程把 binlog 事件写入 relay log 并落盘后就回 ACK」——「落盘」的依据是什么？据我了解半同步的 ACK 在事件写入 relay log 后即发出，是否 fsync 取决于 sync_relay_log（默认 10000，并非每事件刷盘）。若如此，这里的保证被写硬了一档，副本侧宕机仍有丢 relay log 的缝，和我做主备倒换时对「确认落盘」的验收口径不一样。

4. 【7.4.1|读不懂】「在本章的 3.9 基线中，默认逻辑向一个分区累计发送至少 batch.size 字节后再切换」——「本章的 3.9 基线」全章找不到定义，第一眼还以为是 3.9 节（书里满篇小节号）。这应当是「以 Kafka 3.9 为版本基线」的意思，但导读和 7.1 都没交代过；另外「攒满 batch.size 再换分区」是 KIP-794（3.3）改出来的行为，与 2.4 的 KIP-480 原始粘性行为不同，这段演进也跳过了。

5. 【7.2.2|术语使用】前一句刚说「quorum 是人工设定的判定票数，不必是多数派」，紧接着把 ODOWN 称为「集群层面的共识判定」——不足数的阈值投票不该叫「共识」，共识协议的核心恰是多数派法定人数。ODOWN 的 quorum 判定与后面 Leader 选举的多数派是两种性质的投票，用同一个「共识」罩住，读者容易把它们划成一类，建议换成「跨实例联合判定」之类的说法。

## 五个建议

1. 【7.5|深度广度】全章容错只有「能容忍几台」一个轴（⌊(N-1)/2⌋、3 主 3 从），「多久恢复」从头到尾没有量级：表 7-1 六个维度全是「能不能」，图 7-5 三条决策路径也没有时间刻度。做可用率预算的读者只能自己把 cluster-node-timeout 15s、down-after-milliseconds、replica.lag.time.max.ms 拼成恢复窗口——建议表或「关键数字」框加一维「典型检测+选举+切换耗时的构成参数」，哪怕只给默认值组合。

2. 【7.2.3|深度广度】「最小拓扑 3 主 3 从」只数了节点数，没数故障域：3 主 3 从若落同一机架、同一交换机，⌊(N-1)/2⌋ 就是纸面容错，一次电源检修全下线。建议在「分片与副本正交」之外再立一轴「副本之间的故障独立性」，点一下 Kafka broker.rack、MGR 多 AZ、Redis Cluster 跨机架放置——电信里统计独立的冗余才算冗余，这是容错设计第一课。

3. 【7.3.2|案例示例】「确认超时会降级为异步」一笔带过，但这恰是最值得展开的反模式：保护机制偏偏在网络抖动（最需要它的时刻）静默解除，电信的保护倒换宁可阻塞也不裸奔。建议补一个案例方框：抖动期半同步降级、主库随即宕机丢已提交事务，配上监控点（rpl_semi_sync_master_status 翻转）与 rpl_semi_sync_master_timeout 取多大、要不要禁止降级的取舍。

4. 【7.4.1|版本时效】全章版本口径散落：Redis 只在 7.2.1 冒出一个 Redis 7.0，MySQL 标到 8.0.27，Kafka 从 2.4 标到 4.0，而「本章的 3.9 基线」又无出处。建议在导读声明一行统一基线（如 Redis 7.x / MySQL 8.0.x / Kafka 3.9），正文只讲偏离基线处的版本差异，读者也好自行判断时效。

5. 【7.2.3|图示】丢写「窗口」是本章最要命的概念（导读事故、7.2.3「窗口期内写到少数派老主的数据，可能在转移后被丢弃」、7.3.3 少数派不能确认、7.4.2 无可用 ISR 等待恢复），但全靠文字描述，图 7-5 是决策流程不是时间轴。建议补一张三软件并列的网络分区时间轴图：横轴时间，标出检测超时点、少数派停写点、新主就绪点，把丢写/停服窗口画成区间——一张图顶三段文字。
