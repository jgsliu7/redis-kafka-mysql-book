### Q1【P0|5人共鸣|覆盖5条】序言第三层"组合成整体/组织约束"的承诺在第 10 章落空
- 定位：序言 vs 10.3/10.4/10.5、表 10-2

### Q2【P0|2人共鸣|覆盖2条】appendfsync=always"每批写命令追加后刷盘"疑似与官方口径不符
- 定位：10.2.4
- 摘要：书里把 appendfsync=always 描述为"每批写命令追加后刷盘"，而 Redis 官方口径是"每条写命令 fsync"。读者指出一字之差直接决定 always 的延迟量级，且这格恰是持久化语义最要紧的地方——新手会怀疑逐条落盘的保证，拿去面试/对照官方文档都会被 challenge。
- 代表意见：「appendfsync=always 被描述为"每批写命令追加后刷盘"，而 redis.conf 官方注释是"every time a new command is appended"——每条命令一次 fsync。一字之差直接决定 always 的延迟量级……我拿书里的表述去面试会被 challenge，望核对。」（读者096·跃迁者）
- 其他提出者：099·校招新（"每批"与逐条口径关系未解释，新手会真怀疑 always 的保证）

### Q4【P0|2人共鸣|覆盖2条】规律三断言缺介质与场景边界，会长成错误心智模型
- 定位：10.2.3 规律三（另涉 10.3.1 维度四）
- 摘要：规律三把机械盘寻道、存储 I/O、网络往返、系统调用并列为"值得摊薄的固定开销"，读者指出 HDD 与 NVMe 上随机/顺序差距差数量级、不区分介质会在全闪存部署上过度套用寻道逻辑；另一读者指出"堆 CPU 收益有限"是无限定结论，与本书自己讲的"Redis 单线程难以利用多核"相抵——CPU 密集命令恰是批处理救不了只能靠核的场景。
- 代表意见：「"机械盘寻道、存储 I/O、网络往返和系统调用，都有值得摊薄的固定开销"把机械盘和 SSD 混为一谈：HDD 随机与顺序差约三个数量级，NVMe 上缩小到几倍……不区分介质，读者会在全闪存部署上过度套用寻道逻辑，这正是 DDIA 第 3 章讲 LSM 时专门处理过的边界。」（读者092·DDIA粉）
- 其他提出者：098·课代表（"这句无限定的结论会被学员原样抄进笔记，长成一条错误的心智模型"）

### Q5【P0|1人共鸣|覆盖1条】"AOF 携带信息严格多于 RDB"的绝对化表述存疑
- 定位：3.2
- 摘要："严格多于"这个数学口吻的措辞在特定时序下不成立：BGSAVE 刚完成而 AOF 尾部刷盘落后近一秒的窗口里，RDB 反而更新；而 Redis 加载规则是 AOF 优先、不比较新旧，极端窗口下会恢复到更旧状态。"严格"二字应留出"通常"的缝。
- 代表意见：「手动 BGSAVE 刚完成而 AOF 最后一笔刷盘落后近一秒（everysec 窗口）的时序里，dump.rdb 反而比 AOF 尾部新；而 Redis 的加载规则是 AOF 优先、并不比较两者新旧，极端窗口下会恢复到更旧的状态。"严格"二字应留出"通常"的缝。」（读者100·老法师）

### Q7【P0|1人共鸣|覆盖1条】表 1-1 把 MySQL 的牺牲压缩成"写性能"，压掉正文精度、误导读者

- 代表意见：「表格化时压缩成"写性能"，把正文原有的精度压没了，读者会带走"MySQL 写入天生慢"的错误印象。」（读者091·书评人）

### Q8【P0|1人共鸣|覆盖1条】10.4.3 实验二强杀进程观察不到预期丢失，反会固化"双 0 安全"
- 定位：10.4.3 实验二（innodb_flush_log_at_trx_commit 1→0）
- 摘要：进程被杀时操作系统还活着，page cache 里的 redo 迟早会被刷下去，学员大概率观察到"没丢"，反而固化"双 0 也安全"的错误结论；要演示丢失需断电级故障，书里没提示这个差别——实验设计与教学目标错配。
- 代表意见：「学员大概率观察到"没丢"，反而固化"双 0 也安全"的错误结论。要演示丢失需要断电级故障，书里没提示这个差别；实操实验最忌做出来观察不到预期现象，这一题的实验设计与教学目标错配。」（读者098·课代表）

### Q11【P1|2人共鸣|覆盖2条】10.3.3 练习三论证不完整、"几乎必亏"下得太满
- 定位：10.3.3 练习三
- 摘要：读者认同"先顶住再切"的结论，但指出推理链缺环：读写分离的复制延迟过期读（新业务头一个月最常踩的坑）只字未提、"到瓶颈再分片"成立的前提是分片键建模期已选好；另有读者指出书里只有成本账没有风险账——等瓶颈出现再切意味着生产高压下带存量数据的大迁移，恰是事故高发期，且没给"出现什么信号就必须早切"的判据。

### Q17【P1|2人共鸣|覆盖2条】表 10-2 答案颗粒度不一、扩容路径覆盖不全
