# 读者126 · 逆向仔
身份：逆向工程师，7年，爱好：标本制作
主读：第 6 章

## 五个问题

1. 【6.2|技术事实】"凭证存储上，密码以 SHA-256 摘要形式保存，不存明文"只对 ACL 用户密码成立；走 `requirepass` 的存量部署密码是明文躺在 redis.conf 里（CONFIG REWRITE 也按明文回写），`CONFIG GET requirepass` 还能直接回显。做入侵复盘我第一步就是 cat 配置文件，这句话会让人把 Redis 静态凭证的暴露面估小。

2. 【6.2|深度广度】caching_sha2_password 的完整认证把"安全连接或 RSA 加密的密码交换"并列为两条路，但不固定服务器公钥的 RSA 路挡不住中间人——伪造服务端下发自己的公钥，"加密过的密码"就是加密给攻击者的。官方把 TLS 当正路、RSA 当退路（用 serverPublicKeyPath 固定公钥才补上这个洞），书里不标两条路的等级差，读者照抄配置会踩坑。

3. 【6.3|图示】图 6-1 明明画了 TLS 隧道包住整条请求链路，图 6-3 的认证时序却把 "AUTH alice <密码>" 画在裸生命线上，全章也没有一句话点破：不开 TLS 时这个密码是 RESP 明文过网络，tcpdump 里直接可读。两张图对照，容易让读者以为认证环节自带保护。

4. 【6.5|深度广度】评 Redis 审计"弱"没点到最要害的一层：ACL LOG 是默认 128 条（acllog-max-len）的内存环形缓冲，重启即清空，攻击者自己灌几百条被拒命令就能把入侵痕迹从缓冲里挤出去。真到取证时它多半已经不在了——"弱"弱在证据不存活，这比"覆盖不全"严重。

5. 【6.2|读不懂】"SCRAM 可以用于 Broker 间通信，Kafka 3.5.0 也加入了 Broker 到 Controller 的 SCRAM 支持；这与 Controller 之间的共识连接不是同一条路径。后者在 3.5.1、3.6.0 曾出现用 SCRAM 启动集群失败的问题"——三层嵌套我读了三遍才分清"B2C 认证"和"Controller 间共识"是两条路径，且"曾出现问题"不给 KIP/JIRA 编号（我事后查应该对得上 KAFKA-15513），现场想追根的读者没有抓手。

## 五个建议

1. 【6.2|案例示例】把"未授权 Redis 写 SSH 公钥、写定时任务导致 RCE"展开成一个三步攻击链框图：CONFIG SET dir 指到 ~/.ssh、dbfilename 设成 authorized_keys，SET 写入公钥载荷，SAVE 落盘。逆向上见过太多这条链的变种，画出来读者才真正理解"一个缓存怎么会变 RCE"，还能自然衔接 6.3 里键模式、命令类别分别在链路哪一步把它掐断。

2. 【6.4|图示】MySQL TDE 建议补一张密钥层级图：keyring 里的 master key、各表空间密钥、redo/undo 与 binlog 的加密密钥各挂哪层，配一句 ALTER INSTANCE ROTATE INNODB MASTER KEY 只换顶层、不动数据页。我拆存储格式时最想先搞清的就是"哪把钥匙保护哪块、轮换波及谁"，现在这段全靠文字脑补。

3. 【6.5|深度广度】审计小节加一张三家"证据存活"对照表：证据存在哪（内存/文件/日志级别）、重启还在不在、有权限的攻击者能否冲掉或关掉（Redis ACL LOG 会被环形挤出、MySQL general log 能被 SET GLOBAL 关掉、Kafka 放行记录要 DEBUG 级别才落盘）。做事后取证的人真正需要的是这张表，也正好坐实本章"审计几乎总是外挂"的判断。

4. 【6.3|案例示例】Kafka 前缀授权只给了 `--resource-pattern-type prefixed --topic app-a.` 一个片段，建议补一条可复制的完整 kafka-acls 命令（含 --add、--allow-principal、--operation），再加"逐主题配 N 条 vs 前缀配 1 条"的前后对比。Redis 有完整 ACL SETUSER 示例、MySQL 有四类权限清单，三家的示例密度在 6.3 明显不齐。

5. 【6.6|版本时效】全章版本锚点口径建议统一：正文写"在 Redis 7.0 的实现中""在 Kafka 3.9 中"，表 6-1 又用 7.x/8.0/3.x，MySQL 小节混排 8.0.4/8.0.1/8.0.14/8.0.24，读者拼不出自己手上的版本到底有哪些能力。另外 6.4 的日志加密参数只标版本不标发行版归属（keyring 那里区分了企业版/社区版，这里口径断了），社区版用户没法对照自己的发行版核实。
