## 三席发现吸收情况

| 三席发现 | C 版处置 |
|---------|---------|
| #1 「页内挪动」机制不准+无承接（双席） | ✅ 换为「删一条旧条目、插一条新条目」（准确且自含画面） |
| #2 论点句假区分因素（按序拉取）+介质不对称 | ✅ 「跳表天然适合…而…」整句删除；区分因素回到改分+名次；B+树句保留且介质归位 |
| #3 大 O 论证错位（B+树插入也 O(log N)） | ✅ O(log N) 只作为 ZSET 侧属性陈述，对比论据换成「没有页，也就没有分裂」（无页分裂/局部指针手术，正确口径） |
| #4 导读 O(log N) vs 正文 O(log N+M) 落差 | ✅ 按序拉取复杂度不再出现，落差消失 |
| #5 缺代价/结果一拍（双席） | ⚠️ 未吸收（C 无结果拍/代价拍）——作者选 C 即裁定接受 |

| ZRANK→ZREVRANK（技术席⚪） | ✅ |
