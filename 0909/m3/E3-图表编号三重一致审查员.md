### P1（强烈建议关注，3 项）

**P1-1. SVG 内图号嵌入覆盖率低（56/57 = 98.2% 缺失）**

- **现状**：主线版本仅 fig-10-1.svg 内嵌"图 10-1"文字，其余 56 张 SVG 无嵌入图号。GPT 5.6 重写版则全部 53 张有嵌入图号。
- **原因**：`build_html.py` 第 22-25 行在构建时**主动剥离** SVG 内图号文字：
  ```python
  # 剥离图内"图 X-Y 编号标题"行：下方 figcaption 已承担编号标题，留着会上下重复。
  # 仅构建时剥离；.svg 源文件仍自带标题，单独打开不受影响。
  m = re.search(r'<text\b[^>]*>\s*图\s*\d+[-－]\d+\s*[^<]*</text>', s)
  if m:
      s = s[:m.start()] + s[m.end():]
  ```
- **影响**：单独打开 SVG 文件时，读者看不到图号（只能通过 HTML figcaption 看到）。GPT 重写版反而保留了嵌入图号。
- **修法建议**：
  1. **方案 A（不改构建系统）**：保留现状——HTML 中 figcaption 已完整承担图号标题功能，单独 SVG 用途是嵌图而非独立阅读，不强制要求图内嵌入编号。
  2. **方案 B（对齐 GPT 重写版）**：为 56 张缺失 SVG 补嵌"图 N-M　标题"文字（需逐张操作，由 svg-illustrator agent 执行）。
