### P0-1：序言完全缺失商标声明段（硬伤，与历史审查重复未修复）

**位置**：`chapters/00-preface.md`
**问题描述**：全书序言（Preface）中无任何商标声明段落。2026-07-05 compliance agent（C01）报告与 G6-global-trademark 三席审查均明确指出此问题，要求在序言 L34"是为序。"前插入商标声明段。但截至本轮审查，该段仍**未补入**。这是本书目前唯一的 P0 合规硬伤。
**现状**：序言仅包含正文、版本约定、AI 披露三段，末尾"是为序。"前无任何法律声明。
**修法**：在 `chapters/00-preface.md` "是为序。" 前插入：

```markdown
## 商标声明

本书提及的商标与产品名称均属其各自所有者。Redis® 是 Redis Ltd. 的注册商标。MySQL® 与 InnoDB® 是 Oracle Corporation 及其附属公司的注册商标。Apache Kafka® 是 Apache 软件基金会（Apache Software Foundation）的注册商标。Apache ZooKeeper™ 是 Apache 软件基金会的商标。Linux® 是 Linus Torvalds 在美国及其他国家的注册商标。本书对上述商标的使用仅用于指代对应的软件产品，不表示与各权利人之间存在任何关联、背书或赞助关系。
```
**优先级**：P0，必须在出版前修复，不可绕过。

### P0-2：后记商标声明使用无符号纯文本，覆盖不全

**位置**：`chapters/10-epilogue.md` L63
**问题描述**：后记版权页的商标声明段落**使用了无符号纯文本**，写成"Redis 是 Redis Ltd. 的商标；MySQL 是 Oracle Corporation 及其关联公司的商标或注册商标；Apache Kafka、Kafka 是 Apache Software Foundation 的商标"，既未加 ®/™ 符号，也未声明 InnoDB、ZooKeeper（均需声明）。这是本书目前**唯一的在案商标声明**，但它不合格。
**当前文本（L63）**：
> 商标声明：Redis 是 Redis Ltd. 的商标；MySQL 是 Oracle Corporation 及其关联公司的商标或注册商标；Apache Kafka、Kafka 是 Apache Software Foundation 的商标。本书对上述名称的使用仅作技术讨论，不代表各商标权属方对本书内容的认可。

**问题**：
- Redis 应为 **Redis®**（Redis Ltd. 注册商标）
- MySQL 应为 **MySQL®**（Oracle 注册商标）
- Kafka 应为 **Kafka®**（ASF 注册商标）
- InnoDB 未列入（Oracle 注册商标，正文出现 105 次）
- ZooKeeper 未列入（ASF 商标，正文出现 33 次）
- Linux 未列入（®）
**修法**：替换 L63 为：

```markdown
商标声明：Redis® 是 Redis Ltd. 的注册商标；MySQL® 与 InnoDB® 是 Oracle Corporation 及其附属公司的注册商标；Apache Kafka® 是 Apache Software Foundation 的注册商标；Apache ZooKeeper™ 是 Apache 软件基金会的商标。本书对上述名称的使用仅作技术讨论，不代表各商标权属方对本书内容的认可。
```
**优先级**：P0，与 P0-1 同时修复。声明样板见 §4。

### P1-1：三家核心商标正文零标记

**位置**：全书正文（ch01–ch10），Redis/MySQL/Kafka 各自出现 600–700+ 次
**问题描述**：正文首次提及 Redis、MySQL、Kafka 时，以及全书所有后续提及处，均未使用 ®/™ 符号。正文零标记是出版社惯例中"严格做法"的要求（宽松做法仅需序言集中声明，详见 C01 报告）。若出版社要求正文标记，则每章首次出现均需加 ®/™。
**当前标记状态**：0 处
**修法**：两步走——(1) 先确认出版社要求；(2) 若要求严格标记，在各章首次出现处加一次 ® 即可（示例："Redis® 在 2009 年由 Salvatore Sanfilippo 创建……"），不必全文穷追。
**优先级**：P1，建议与 P0-1/2 同时处理，由作者决定是否前置。

### P1-8：部分参考文献 URL 使用版本未锚定

**位置**：`chapters/11-references.md` L14、L51
**问题描述**：
- 参考文献 [5]：链接为 `https://github.com/redis/redis/tree/7.0.0/src`，指向 Redis 7.0.0 源码。7.0.0 属历史版本，GitHub 可能保留但非最新，建议锚定稳定 tag 或说明引用目的（"为对照第 2 章叙述，以特定版本为基准"）。

**修法**：在参考文献条目后加括号注释，说明"以 X 版本为对照基准"，或在 URL 中改用 `tree/mysql-8.0` 分支。
