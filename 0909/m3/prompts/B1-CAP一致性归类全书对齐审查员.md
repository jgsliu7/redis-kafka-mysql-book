## 检查方法
1. **盘点所有归类句**：
   - 包含："AP""CP""一致性""一致性模型""最终一致性""强一致""异步复制""同步复制""半数派"
   - 包含主语：Redis / MySQL / Kafka / Redis Cluster / 半同步 / 组复制 / KRaft
   - 表格里出现"CAP"或"一致性"列的条目（每章 N.5 横向对比表）
2. **立场分类**：
   - **绝对归类**（危险）："Redis 是 AP""MySQL 是 CP"
   - **限定归类**（较好）："Redis 默认偏 AP""在 X 场景下 Y 走 CP"
   - **谨慎立场**（理想）："归类有争议""社区对此有不同看法""本书不作绝对归类"
3. **跨章一致性核**：每个归类句是否与 ch7 立场一致？ch6/ch9/ch10 是否对齐？
4. **表 9-1 / 表 7-1 / 表 6-1 横向对比表**：CAP 列表述是否一致？
5. **场景依赖**：是否讲清了"归类依赖场景"（异步复制 ≠ 永远丢；半同步 ≠ 永远不丢）
