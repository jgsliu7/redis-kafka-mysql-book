## 5. 发现的问题

### P1：Redis `protected-mode` 引入版本的表述歧义

**位置**：`ch06 §6.2`（ch6 第 112 行）

**原文**：
> `protected-mode`（保护模式，3.2.0 起引入，默认开启）提供另一道限制：**在 Redis 7.0 的实现中**，保护模式开启且 default 用户带有 nopass 标记时，会拒绝非本地连接……

**问题**：括号内"3.2.0 起引入"表述正确，但紧接着"在 Redis 7.0 的实现中"这个措辞容易让读者误认为这是 7.0 版本的特有行为，而非 7.0 只是"按 3.2.0 以来的机制运行"。protected-mode 自 3.2.0 起就按此逻辑运行，7.0 并未改变这一行为。

**影响程度**：保护模式是 Redis 常见安全配置项，读者若误以为 7.0 引入了新的保护机制，可能在降版本使用时报错，或低估了旧版本（3.2+）已有的安全门槛。

**建议修订**：将"在 Redis 7.0 的实现中"改为"当 `protected-mode` 开启且 default 用户带有 nopass 标记时"，删除"在 Redis 7.0 的实现中"这一限定语，避免暗示 7.0 有版本特有行为。
