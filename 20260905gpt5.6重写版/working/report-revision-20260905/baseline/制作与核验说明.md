## 构建

在仓库根目录执行：

```bash
python3 20260905gpt5.6重写版/scripts/build_book.py
python3 20260905gpt5.6重写版/scripts/check_content.py
```

构建器只依赖 Python 标准库，固定读取本目录书稿并输出本目录成品；不会运行旧构建器或覆盖原稿产物。书稿单元缺失、代码围栏未闭合、SVG 不存在、重复 ID、失效页内链接或外部资源依赖会触发错误。图表和章节链接映射到真实锚点。

`make_diagrams.py` 是本轮 SVG 制作源。重新生成时会只读仓库原稿的少量结构图作为几何底稿，因此搬走本目录以后，不应把它当成完全独立的图形生成工具；已经交付的 SVG 及 HTML 构建不需要原稿目录。手工修改 SVG 后直接运行 `build_book.py` 即可，不要再运行生成器覆盖手工修改。

浏览器和打印检查脚本为 `render_check.cjs`、`check_print.cjs`，本机使用已安装的 Chrome、Playwright、Sharp、PDF.js 与 Canvas。脚本中的本机运行库路径需在其他机器调整；阅读成品和 Python 构建不依赖这些工具。

## 本轮实际完成的核验

- 10 章实质重写；每个书稿单元由两位非执笔审稿者完整通读，技术、比较边界、作者经历、交叉一致性与表达分别复核。专精审查后另完成一次全部 13 单元的病理语义通读，已确认问题由原执笔者精确修订，合并段的存量句重新阅读。
- 57 张 SVG 全部逐图进行源码语义交叉审阅；最终制作员实际查看全部 57 张渲染图的联系表及关键单图，另一审稿者也实际查看全部联系表和桌面、窄屏样图。图中哈希扩容目标、WAL 独立刷页路径、RDB 元数据顺序、日志读取边界与分叉恢复等已按正文校准。
- 最终 HTML 包含 13 个书稿单元、57 张不同的内嵌 SVG。重复 ID、失效页内锚点、外部资源依赖均为零；构建记录见 `qa/build-audit.json`。
- 逐单元比较源稿与 HTML 的正文汉字顺序，去除重复图像替代文字和 SVG 图内文字后，13 个单元的汉字序列完全相同。15 个代码围栏与 HTML 中 15 个代码块的解码文本逐块多重集相同，保留缩进，仅忽略末尾换行。正文资料 URL 均已出现在正式参考文献中。详见 `qa/content-audit.json`。这些检查不替代对数字、代码含义和技术事实的审核。
- 用 Chrome 实际打开本地 HTML，验证 1440×1000 桌面、390×844 窄屏；无页面整体横向溢出、脚本错误或 HTTP 资源请求。目录展开、跳到第 10 章并收起的交互正常。全部 57 张 SVG 在浏览器中的文本包围框没有超出自身 viewBox。详见 `qa/browser-audit.json`。
